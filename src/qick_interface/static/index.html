How to measure

More detail: user guide

Steps, in order

  1. Take control. Type Your name, press Take control. Only the controller changes settings; everyone else watches live. Talk to the current controller first.
  2. Calibrate the board's power (once per board; needed for dBm). In Setup → Board:
    1. DAC: measure each DAC's output at gain 1 at a few frequencies with a signal analyzer. Type them in its output at gain 1 table (one "MHz dBm" per line), set Source, press Save board.
    2. ADC, from a loopback: cable a DAC to an ADC with a short cable, pick them in From DAC and To ADC, press Calibrate ADC from loopback (a few seconds).
    Until then both use the data sheets. Shared by every chip.
  3. Set up the chip. Press Setup: chip name, LO frequency (empty with no mixer) and sideband, output and return path (Real or I/Q) with their DACs and ADCs, and a Control line if the qubit tone has its own DAC (fluxonium). Press Measure next to Time of flight, then Save setup.
    • The LO: unless the app was started with --lo (the status bar then shows the LO it set), set the CXG by hand to the setup's LO frequency and power, RF on. The app only uses the value to convert between RF and IF; a wrong LO puts every frequency off, with no warning.
    • Flux bias (fluxonium) is set by hand on its current source, outside the app.
    • Frequencies you type are RF, in MHz. On a control line the qubit frequency is the DAC's own (no mixer, up to 4915 MHz).
  4. I/Q chips only: calibrate the mixers. After every board power-up, Setup → I/Q cal → Measure the Q delay (both DACs on the scope). Then Tone on and adjust Q phase and Q / I gain until the image on the spectrum analyzer is smallest; save. With an I/Q return, run RX I/Q calibration and press Marker → Store in setup: RX calibration.
  5. Find the resonator. Resonator sweep: set Start and Stop, Run sweep. Once per setup, run a wide sweep and press Marker → Store in setup: electrical delay. Then Marker → Min and Marker → Readout frequency.
  6. Find the qubit. Two-tone spectroscopy: sweep the qubit tone (the readout frequency is already filled in). Put the marker on the dip or peak, press Marker → Qubit frequency.
  7. Calibrate the π pulse. Rabi, Sweep = Amplitude: press Marker → Store π-pulse gain when the fit shows it. Or Sweep = Length, to find the π-pulse length.
  8. Check the pulses (optional). In Two-tone or Rabi, Output → Play sequence repeats one shot; trigger the scope on PMOD0_0 (1.8 V). Off stops it.

Each step fills in chip parameters that the next measurement starts from. Stop ends a run after the current round; every run is saved in data/<date>/.

Measurements

Resonator sweep
|S21| and phase against frequency. Pulsed (default), or CW with the tone always on, for high-Q resonators.
CW Time
|S21| and phase against time at one frequency, sweep after sweep until Stop. Watches drifts and jumps.
Two-tone spectroscopy
Sweeps a qubit tone, then reads out at the resonator. Set the repetition delay to about 5×T1.
Rabi
Amplitude: a Gaussian pulse of width Gaussian σ, gain swept. Length: the pulse length swept, with Shape Flat or Gaussian edges (smoother, for fast drives; half the drive at the same gain).
RX I/Q calibration
Balances the two ADC paths of an I/Q return (gain, phase, delay). Only for an I/Q return path.

Display and settings

Menus
The keys on the right hold each measurement's settings. A menu shows only what applies to the current mode. Gain fields show their drive power in dBm.
Scale
Autoscale, or a fixed scale per division and reference. Units: relative, or absolute power at the ADC (dBm, mV).
Marker
Click a trace to place it. Min, Max, and keys that store the value in the chip's parameters.
Setup → Board
The power calibration of the DACs and ADCs (step 2), behind the dBm units and the drive power hints.
